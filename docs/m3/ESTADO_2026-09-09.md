## 0. Por qué v1 → v2 (contexto, para no re-preguntarlo)

El portafolio **v1** (`main` → Netlify, CONGELADO) tenía 3 fallas de raíz — ver
`docs/m0/PROJECT_MANIFEST.md §"Problema que resuelve"` y `ADR-004`:

1. **Arquitectura iframe.** El contenido vivía en `public/original/index_clean.html`
   (3.325 líneas de HTML estático) servido dentro de un `<iframe overflow:hidden>`.
   Los `IntersectionObserver` no disparan dentro del iframe → **las secciones en
   scroll eran invisibles** (~40% del contenido no se veía).
2. **DNA incompleta.** El agente RAG (TitanRAGAgent) tenía 7 de ~20 proyectos →
   no podía responder sobre el 65% de la trayectoria real.
3. **TITAN v5.0 en producción** cuando el framework ya iba por v7.0 — el sitio no
   reflejaba el estado real del método.

**v2** = reconstrucción **desacoplada**: Next.js 15 + React 19 + MUI v6 + tokens M3
+ Storybook 8, sin iframe, todo el contenido en componentes React nativos, rama
`v2` → Vercel. `main` queda como backup operativo (solo cherry-picks de fixes P0).

La migración de contenido v1→v2 se ejecutó en **Fases A→F** (ver
`ESTADO_2026-09-07.md`): estructura de casos, 5 componentes nuevos, contenido
tipado de work-tests + 8 casos de cliente + meta-caso, páginas
`/pruebas-tecnicas`, `/metodologia`, `/excalibur`, y la portada completa (9
secciones en el orden de v1). Esta sesión (09-09) cierra la **exactitud** de ese
contenido y la **calidad técnica** (responsive, a11y, iconos, i18n).
