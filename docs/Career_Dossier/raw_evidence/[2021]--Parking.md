# **Pestaña 1**

Esta carpeta contiene una documentación exhaustiva sobre el ecosistema digital de **Parking** y **Ruedaz**, centrada en la transformación de la experiencia de parquear mediante tecnología.

### **1\. Procesos Realizados**

> * **Diseño de Producto de Extremo a Extremo:** Definición de flujos para múltiples plataformas: App (Android/iOS), Web, Portal Corporativo, **Parking Inside** (administrativo) y **Parking Attendant** (operativo).  
> * **Mapeo de Experiencia (CUJ):** Creación de *Customer Journeys* detallados para usuarios recurrentes, clientes B2B y procesos de fidelización (*Be Parking*), identificando momentos críticos (*MOTs*) y puntos de contacto.  
> * **Estandarización UI/UX:** Desarrollo del **Ruedaz System Design**, estableciendo principios de navegación, accesibilidad (WCAG 2.1), consistencia visual y uso de marcos como *Material Design* y *Atomic Design*.  
> * **Gestión de Reglas de Negocio:** Documentación técnica de criterios de aceptación para registro, suscripciones, renovaciones automáticas y validación de cupones mediante escaneo de facturas.  
> * **Estrategia de Comunicación Omnicanal:** Diseño de matrices para mensajes Push, SMS, E-mail y Pop-ups, segmentados por eventos del ciclo de vida del usuario (ej. recordatorio de 15 min antes de cumplir 3 horas).  
> * **Definición de MVP Corporativo:** Sesiones de validación de oferta de valor para servicios como validados, VIP, convenios y gestión de "Monedero Corporativo".

### **2\. Metodologías Identificadas**

> * **UX Research:**  
  * **Generativa:** Entender necesidades y anhelos de usuarios.  
  * **Evaluativa:** Pruebas de guerrilla, *Think Aloud*, pruebas de 5s y Test A/B.  
  * **Técnicas de Observación:** *Shadowing*, diario de campo y arqueología de datos.  
> * **Marcos de Trabajo (Frameworks):**  
  * **Design Thinking / Sprint Design:** Procesos de 5 fases para reducir riesgos en nuevos lanzamientos.  
  * **Jobs to be Done (JTBD):** Enfoque en el "porqué" del usuario para crear propuestas de valor.  
  * **Agile:** Implementación de *Scrum* para desarrollo incremental y *DesignOps/DevOps* para optimización de procesos.  
> * **Ideación:** Uso de SCAMPER, diagramas de afinidad, conexiones forzadas y lluvia de ideas (escritos/dibujos).

### **3\. Skills (Competencias) Evidenciadas**

> * **Arquitectura de Información:** Diseño de *sitemaps*, flujos de navegación (*wireframes*) y organización jerárquica de contenido.  
> * **Diseño Visual y Branding:** Creación de guías de estilo, sistemas de color, tipografía y manuales de marca digital.  
> * **Pensamiento Estratégico:** Definición de KPIs, análisis de ROI en UX y alineación de objetivos de negocio con necesidades del usuario.  
> * **Prototipado de Alta Fidelidad:** Manejo de herramientas como **Figma**, **Sketch**, **Zeplin** y **Miro** para la colaboración y entrega a desarrollo.  
> * **Análisis de Datos:** Revisión de analíticos y métricas para la mejora continua del producto.

### **4\. Cronogramas y Proyectos Clave**

> * **Hitos Relevantes:** El proyecto incluyó la constitución de la sociedad en May 2020, entrega de marca en Jun 2020 y publicación en tiendas en Jul 15, 2020\.  
> * **Productos Específicos:** Gestión de **Suscripciones** ($59,900/mes), **Valet Parking** (con seguimiento en tiempo real), **Reserva** de cupos y **Cortesías** corporativas.

# **Pestaña 2**

El contenido de esta carpeta se centra principalmente en el desarrollo de la experiencia de usuario (UX) para los proyectos de la marca **Ruedaz** y **Parking**, abarcando la aplicación móvil, la web y plataformas internas como Inside y Attendant.

**Temas principales y proyectos clave:**

1. **Proyectos UX/UI (Ruedaz y Parking):**  
   * Se detalla la planificación de tareas de UX, incluyendo la recepción de requerimientos, análisis de arquitectura de la información, desarrollo de *wireframes*, diseño de pantallas y desarrollo de prototipos.  
   * Se identifican funcionalidades específicas para la **App y Web de Ruedaz** (como la gestión de *customer journey*, cambio de placa, portal empresarial, suscripciones y pagos) y para **Parking** (entrada/salida de parqueaderos, pago por minuto, arquitectura de información y diseño).  
   * Se incluye una matriz de módulos y funcionalidades clave para la **App de Ruedaz** y su versión responsiva, cubriendo *onboarding*, autenticación, mapa, detalles de parqueaderos, servicio activo, planes y pagos.  
   * Existen *mockups* de pantallas para la aplicación Ruedaz (inicio de sesión, mapa, suscripción, mi cuenta) y de un Dashboard para Parking.  
   * Se mencionan diseños específicos para **Parking Inside** (Administrador, Parametrización, Personal, Operaciones, SAC, Comercial, Legal) y **Parking Attendant** (Aperturas y cierres, Movimientos, Siniestros, Consulta).  
   * Se proporcionan enlaces de Figma para los proyectos **Ruedaz App, Ruedaz web, Parking web, Inside MVP, Attendant** y **Blomi**.  
2. **Experiencia y Viaje del Cliente (*Customer Journey*)**:  
   * Se encuentra un documento sobre el *Customer Journey* de un **Cliente Recurrente Parking**, detallando los pasos, puntos de contacto (*Frontstage* y *Backstage*), y las experiencias positivas y negativas.  
   * También se incluye un *Journey* para el **Cliente B2B** que compra suscripciones para regalar, desde la captura hasta la gestión de suscripciones.  
   * Hay un diagrama del *Customer Journey* general con fases de *Antes, Durante* y *Después* del uso del vehículo, incluyendo puntos de contacto.  
3. **Investigación y Comunicación:**  
   * Se listan diversas **metodologías de investigación UX** (Generativa, Círculo de preguntas, Mapa de empatía, Journey map, Pruebas de usabilidad, etc.).  
   * Hay matrices de **comunicaciones** (Push Notification, SMS, E-mail, Pop-up, In-app message, Whatsapp) para la App de Ruedaz, segmentadas por momento del usuario (registro, inicio de sesión, suscripción, ingreso/salida de parqueadero, etc.).  
   * Se encuentran contenidos de redes sociales y campañas de mercadeo para Ruedaz, enfocados en seguridad, ahorro y la red de parqueaderos.  
4. **Reglas de Negocio y Flujos:**  
   * Un documento detalla las **Reglas de Negocio** para Ruedaz, cubriendo la descarga, registro, inicio de sesión, funcionalidad del mapa, obtención de prueba gratuita y compra de suscripción.  
   * Se describe la estructura para la gestión de parqueaderos (*Dash Corp RUEDAZ V1*) y el proceso de escaneo de facturas para obtener cupones (*ScanProcess*).  
   * Se define la funcionalidad para la **Reserva** de parqueadero a tarifa preferencial y el producto **Recarga Monedero Corporativo**.
