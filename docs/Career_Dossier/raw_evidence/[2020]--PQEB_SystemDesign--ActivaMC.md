# **Pestaña 1**

Basado en los archivos de la carpeta **\[2020\]--PQEB\_SystemDesign--ActivaMC**, se presenta una consolidación minuciosa de la documentación técnica y estratégica del proyecto:

### **Detalle Consolidado de la Carpeta**

La carpeta documenta el diseño y aseguramiento de calidad (QA) de la plataforma **"Porque Quiero Estar Bien" (PQEB)**, desarrollada por **Activa MC** entre **Dec 2020** y **Jan 2021**.

#### **1\. Procesos Realizados**

> * **Aseguramiento de Calidad (QA) y Testing**:  
  * Revisión estructural y funcional exhaustiva de componentes core: Header, Home, Categorías, Filtros, Búsqueda y Artículos.  
  * **Validación Crossbrowsing**: Pruebas de estabilidad en las dos últimas versiones de navegadores (Chrome, Firefox, Safari, Edge) sobre múltiples SO (Windows, iOS, Android) y dispositivos (PC HD, Tablets, Móviles).  
  * **Auditoría de Errores**: Identificación y clasificación de fallos mediante nomenclatura técnica (e.g., EEI: Especificaciones erróneas, EDL: Error diseño lógico, ICI: Interfaz inconsistente).  
> * **Diseño de Experiencia de Usuario (UX)**:  
  * Arquitectura de flujos para un **Test Emocional** interactivo con lógica de puntuación y resultados condicionales.  
  * Definición de estados de usuario (Login, Registro, Recuperación de contraseña) y componentes de interfaz.  
> * **Diseño de Interfaz (UI) y Front-end**:  
  * Creación de un sistema de diseño con cuadrícula de 12 columnas (825px) y tipografías específicas.  
  * Implementación de kits de fuentes web y estilos CSS para asegurar consistencia visual.

#### **2\. Skills Identificados**

> * **QA / Software Testing**: Pruebas funcionales, reporte de *issues* críticos, validación de compatibilidad entre navegadores y dispositivos.  
> * **UX/UI Design**: Diseño de interacción (IxD), flujos de usuario complejos (*Overflow*), prototipado de alta fidelidad, diseño de estados (vacíos, error, carga).  
> * **Desarrollo Front-end**: Manejo de CSS avanzado (@font-face, grid systems, resets), integración de fuentes web (TTF, WOFF, EOT, SVG) y gestión de activos visuales.  
> * **Gestión de Producto**: Clasificación de impacto de requerimientos (Correcto, Incorrecto, Crítico), seguimiento de estatus (En Proceso, Corregido, Revisado) y planificación de Sprints.

#### **3\. Metodologías**

> * **Agile / Scrum**: El proyecto se estructura en **Sprints** (mención explícita a correcciones para el "2do Sprint") con roles definidos para la recepción y revisión de documentos.  
> * **Atomic Design**: Evidenciado en la estructura de la librería de fuentes y componentes reutilizables.  
> * **User-Centered Design (UCD)**: Aplicado en el Test Emocional para guiar al usuario desde las instrucciones hasta resultados personalizados y canales de ayuda inmediata (Botón de Pánico, WhatsApp).  
> * **BPM (Business Process Modeling)**: Mapeo de procesos de negocio y flujos de navegación para asegurar la operatividad del sistema.

# **Pestaña 2**

La carpeta que has seleccionado, nombrada **\[2020\]--PQEB\_SystemDesign--ActivaMC**, contiene documentación y recursos relacionados con el diseño de un sistema o plataforma llamado **"Porque Quiero Estar Bien" (PQEB)**.

Los archivos indican que el contenido se centra en tres áreas principales:

1. **Aseguramiento de Calidad y Pruebas (QA):**  
   * Existe un documento (Excel) de **Revisión y Documentación de Pruebas de Calidad** (PQEB Pruebas ASQ Borrador) que detalla una revisión estructural y funcional realizada entre diciembre de 2020 y enero de 2021\.  
   * Este documento revisa funcionalidades como: Sistemas Operativos (Windows e iOS), **Crossbrowsing**, Navegación general (*Header*), *Home*, Páginas de categorías y contenido, y Búsqueda.  
   * Se utiliza una tabla de validación de *Crossbrowsing* en navegadores (Chrome, Firefox, Safari, Edge) para diferentes sistemas operativos y tipos de dispositivos (Windows HD, Tablet Android, Móvil Android, Mac OS HD, Tablet iOS, Móvil iOS).  
   * Además, se identifica y clasifica una lista de **errores** (*Issues*) en Mac OS/iOS, muchos de los cuales tienen un nivel de impacto **Crítico** y están marcados como **Pendientes** para un "2do Sprint".  
2. **Flujo de Usuario del "Test Emocional":**  
   * Un archivo (`TEST Emocional FLow.overflow`) muestra el flujo de un **"Test Emocional"** rápido y gratuito.  
   * El flujo incluye:  
     * Una introducción al test, que busca identificar el estado de ánimo y dar recomendaciones o indicar si se necesita ayuda profesional.  
     * Preguntas (como si ha experimentado poco interés o placer, se ha sentido decaído/a o cansado/a, o ha tenido dificultad para dormir o concentrarse) con opciones de respuesta basadas en la frecuencia (Ningún Día, Varios Días, Más de la mitad de los días, Casi todos los días).  
     * Pantallas de **resultados** que pueden variar desde indicar que "Tu ánimo se ve muy bien" hasta "No estás pasando por un buen momento" o un nivel **Crítico** (por ejemplo, "34 Puntos Nivel Crítico"), con sugerencias de contenido y la opción de contactar a un profesional.  
   * También se observan elementos de navegación y herramientas como el botón **"Evalúa tu estado"** y el **"Botón de Pánico"**.  
3. **Recursos de Diseño y Desarrollo Web:**  
   * Se incluyen múltiples archivos de imagen (SVG y PNG), incluyendo ilustraciones, logotipos de aliados (como Fundación Santo Domingo y Profamilia), y recursos visuales.  
   * Hay archivos CSS que definen estilos y estructuras de cuadrícula (grid\_12-825-55-15.css) y fuentes web (`fonts.css`, con referencias a `object_sansbold`, `object_sansheavy`, `object_sansmedium` y `tt_interfacesregular`).

En resumen, la carpeta contiene los artefactos de un proyecto de desarrollo web para la plataforma **"Porque Quiero Estar Bien"**, incluyendo la documentación detallada de sus pruebas funcionales y de navegadores, el flujo de usuario del "Test Emocional", y diversos recursos de diseño y estilos CSS/fuentes.
